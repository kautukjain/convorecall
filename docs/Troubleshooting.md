# Troubleshooting

| Symptom | Check |
|---------|--------|
| `pnpm install` fails | Node ≥ 20, pnpm 9 |
| Upload 413 | Raise body size limit; check file MIME |
| Empty notes | Job exit status; evidence gate logs |
| STT timeout | Budget governor; fixture mode |
| Share 404 | Token expiry / wrong id |

Never paste API keys into issues.
